A travel poster for a place that does not exist: the Floating Isles of
Velmora, where a lighthouse stands on a drifting island above a sea of
clouds at golden hour. `main.py` draws the 1024×1024 poster from scratch
in pure Python 3 standard library — its own canvas, bitmap letterforms
and PNG encoder, no network, no installed packages — and writes it to
`/output/entry.png`. Deterministic: no clock, no randomness, so two runs
write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
