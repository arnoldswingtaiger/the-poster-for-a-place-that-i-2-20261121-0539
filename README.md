Velmora is not on any map. This poster is an invitation to go there
anyway: a lighthouse keeping watch on a drifting island, a waterfall
spilling off its edge into a sea of clouds, and the sun going down
between the isles at golden hour.

Everything is drawn by `main.py` in plain Python 3 with no packages
beyond the standard library — the picture surface, the blocky letter
shapes and the PNG writer are all built in the file, so it runs in a
bare sandbox with no network. Give it a run and it writes a
1024×1024 poster to `/output/entry.png`. Run it twice and the two
files come out byte for byte the same: no clock, no randomness, no
input files.

## Try it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
